# Official platform review

[中文](reference-platform-review.md) · [Free API guide](free-api-guide.md) · [Free LLM models](free-models.en.md)

Reviewed on 2026-11-16. This review follows the eight Chinese and eight overseas platforms in the [official free-allowance section of free-newapi](https://github.com/kirito8/free-newapi/blob/7d74d2340de3bd82f211574631fa1c4f5e736a0c/README.md). That list supplies discovery leads; catalog policies and model eligibility are based on the first-party sources below.

Provider policies and model metadata have separate review dates. Existing model dates are preserved, including OpenRouter's 2026-11-16 API inventory. Relevant excerpts, extracted policy fields and hashes of the page text read during review are stored in [source_snapshots.json](../data/source_snapshots.json).

## Conditions to retain when using the catalog

- SenseNova's rolling five-hour and weekly limits apply simultaneously; they cannot be added or converted into fixed token credits. Flash-Lite can fall back to available general points. Consumption rebates ended 2026-10-27; previously granted rebates keep their original expiry.
- Gemini 4 Hydrogen shares its 1,048,576-token context between input/output; default synchronous maximum output is 65,536. Gemini 3.8 Flash has a 1,048,576 input limit and 65,536 output limit.
- GLM-4.6V-Flash accepts file, video and image inputs, but its guide says these cannot all be understood simultaneously in one request. Unconfirmed SenseNova Flash Lite context/capability fields remain unknown.
- The reviewed NVIDIA hosted model pages say input/output are recorded and used to improve NVIDIA products and AI models. Consider both developer-purpose restrictions and data-use terms.
- This work reviews public official pages and generates catalog records. No authenticated inference requests were made. Account eligibility, actual balances and request success require console checks and API testing.
